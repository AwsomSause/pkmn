# Pokémon Roguelike

A browser-playable Pokémon-inspired roguelike built with TypeScript, Phaser 3 and Vite.

See [GAME_DESIGN.md](GAME_DESIGN.md) for the design and [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) for the milestone plan.

This repository is private. The art and audio come from the director's asset packs (see GAME_DESIGN.md §13 for licensing notes); do not publish builds publicly.
