# Accessibility audit checklist

Run this before each release. Generated by `node tools/a11y-checklist.ts`; do not edit by hand.

## Settings that must work (from the settings list)

- [ ] **High contrast** (now): Stronger contrast for the whole screen.
- [ ] **Performance preset** (now): Low, Medium or High: sets particles, effect and shake strength and sprite idle animation together.
- [ ] **Damage details** (now): Explains each hit: effectiveness, STAB and crits.
- [ ] **Disable all animations** (now): Turns every animation off. Your other choices are remembered.
- [ ] **Battle motion** (now): Full, reduced (no flashing or big movement) or skipped.
- [ ] **Animation intensity** (now): How strong animations look.
- [ ] **Flashes** (now): How strong flashes are. 0% turns them off.
- [ ] **Screen shake** (now): How strong screen shake is. 0% turns it off.
- [ ] **Particle effects** (now): Reduced drops the drifting specks; clouds and fog stay.
- [ ] **Accessibility preset** (now): One choice that sets several settings at once.
- [ ] **Type names in words** (now): Names a move’s type in words next to the coloured art.
- [ ] **Text size** (now): Makes all text larger. Applies to screens you open next.
- [ ] **Dyslexia-friendly font** (now): Swaps the pixel fonts for a wide, even-spaced reading font.
- [ ] **Reduced flash** (now): Caps flashes and shakes at 20% and removes bright full-screen flashes.
- [ ] **Tooltip delay** (now): How long to hover before a tooltip shows. Off hides them.
- [ ] **Damage popup size** (now): How big the floating damage numbers are.
- [ ] **Hold to confirm risky actions** (now): Abandoning a run or resetting needs a held press with a filling ring.
- [ ] **One-handed layout** (now): Bunches the on-screen buttons to the left or right edge.

## Manual checks

- [ ] Whole game can be played with the keyboard only (menus, battles, map, shops, events).
- [ ] Whole game can be played with a gamepad using the default map.
- [ ] Touch controls work on a phone-sized window and nothing is clipped.
- [ ] High Contrast, Dyslexia font and the largest Font size: text stays readable and nothing overlaps.
- [ ] Reduced Motion profile: no shake, flash or large movement anywhere (battles, evolutions, transitions).
- [ ] Reduced Flash: no full-screen flashes more than three times a second.
- [ ] Colour is never the only signal (type markers on; HP bars also show numbers).
- [ ] Sound off: every message that matters is also shown as text.
- [ ] Every button has a visible focus mark and a tooltip or label.
- [ ] Browser zoom 200% and window 800x450: no screen is unusable.
- [ ] No console errors on the title, Hub, map, battle and settings screens.
