- Events and map stops framework (plan M8.75, approved rows; API for other threads). **Found already built:** event scene (`scenes/EventScene.ts`: tinted arena, cast, signature FX, choice cards, outcome chips), attribute checks/thresholds/scaling/meters, hidden "?" stops (Intelligence 50+ reveals one), 2 rest spots per stage with the 6 rest activities, the 12 approved events, friendship (part B). **Added here:** per-type map icons (`ui/stopIcons.ts`, keyed by the event's `stop`), per-stage stop quotas (`balance.events.stopQuotas`: special 1, rare 0-1, trade 1, detour 0-1, merchant 1, drawn from their own seeded stream `event-quota`), 4 stop events (`tools/events/stops.ts`: A Rare Sighting, Shimmering Grass, Trading Post, The Side Trail), detours (battle `chain` 1-3: battles in a row at one stop without healing, `win` pays after the last; `run.eventChain`, no save bump), cards show an attribute badge and "Charisma 45: 70%" (`ChoiceView.attributeValue`), gains fly from the outcome chips to the purse / attribute bars / party / Bag.
  **How to add content (API):** write events in `tools/events/<file>.ts` with the `ev`/`ch`/`out`/`fight` helpers (`tools/events/dsl.ts`), import the list in `tools/build-events.ts`, run `npm run data:events` (it drops hand-merged ids such as the `spooky-*` events: merge by id instead, see the PR). Set `stop` to a map-stop type (`special`, `rare`, `trade`, `detour`, `merchant`, `rest`, `shop`, `heal`, or any other string for the "!" icon). A `stop` listed in `balance.events.stopQuotas` is placed on every stage; otherwise events are drawn by rarity (`rarityWeights`, Luck raises rarer ones) and theme types. Choices: `check: <attribute>` (40% + 1% per point, 5-95%), `requires: [att/meter/item/money/partyType/…]` (threshold; shows greyed with the requirement), `scale` effects from attribute values, meter effects (`good`/`evil`/`rage`/`peace`). Battles: `wild({ shiny, lv, chain })`, `trainer(name, { size, chain, win })`. Tests: `tests/unit/events.test.ts`. Limited: the "?" flip animation on arrival is the existing reveal; hidden stops are about a third of side stops (`hiddenShare`).
