  - **How it works.** Personality = the Bond Engine trait (12) + a quirk, both from the Pokémon's id, so two of one species differ. Chemistry is per pair (0-100, stages Acquaintances/Friendly/Close/Inseparable/Trusted Partners at 0/12/30/55/80) and grows only from shared experiences (boss win +3, close call +3, a rescue +4, evolution +2, scene choices); an ordinary win adds nothing. When you return to the map, one scene is rolled for the transition (seeded by run seed + node, so reload shows the same one; none half the time; nothing repeats within the last 4 scenes, pairs cool down 2 battles). Priority: stage milestone > faint (pact, gathering, comfort, last words) > pre-boss huddle > evolution > newcomer welcome > boss celebration > debrief > campfire > grudge > box sulk > travel.
