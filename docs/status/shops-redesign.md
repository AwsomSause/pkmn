- Shops redesign, slice 1 (Kice 2026-11-02; mock-ups in project files `redesign/shops/`): Kice picked six looks as six kinds of shop, each to get its own stock and a perk. Every shop stop now has a type (`core/shopTypes.ts`, `shopTypeAt`): Poké Mart, Aero Boutique, Kecleon's Bazaar, Supply Depot, PokéNet Shop, or Night Market (after dark, or while Giovanni's Black Market runs). The type comes from a hash of the run seed and the stop's place, so no gameplay roll changes. Built: **Poké Mart** (Shop Channel: pinstripes, category capsules, big rounded tiles that puff up and wobble, a "downloading" bar and a BOUGHT stamp on buy) and **Aero Boutique** (Aero Carousel: goods on a glass turntable in a bubbly sky, Left/Right spins the ring, Up/Down jumps between categories, buying pops a bubble). On both, party icons glow with "CAN USE" for stones and form items, the money counts down, and a buy refreshes the screen in place (no more restart flicker). Mouse: hover focuses, click buys. Framework: `ui/shopStyles/` (one file per look; `ShopScene` keeps state, input and buying), view model `shopView` in `ui/shopLook.ts`. Types not built yet draw as the Poké Mart. Stock and prices are unchanged in this slice. Limited: Sell still uses the old list. Tests `tests/unit/shopTypes.test.ts`, `tests/e2e/shopStyles.spec.ts`.
