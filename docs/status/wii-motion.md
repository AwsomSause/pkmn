- Wii-style menu motion (spec §24; `core/presentation/uiMotion.ts`, `ui/wiiMotion.ts`): one set of short timings (hover 140 ms, press 70, release 240, cursor 200, popup 280, page 300) and a fixed-step spring for the cursor. Every `Menu` gets a rounded, glowing cursor that glides between options with a small overshoot (the ▶ pointer glides too), options slide in one after another when a menu opens, the focused label leans in, a press squashes the cursor and springs back, a disabled option wobbles with the error sound. Card focus frames (`focusFrame`: Starter/Trainer Select, Map, Reward, party lists) snap out and settle each time they move. Every clickable button-sized object in every scene grows (centred) or lifts (top-left anchored) on hover, squashes on press and bounces back on release (`installUiJuice`, in main.ts; big panels and full-screen blockers are left alone; `setData('noJuice', true)` opts out). Pickers (Hub rooms, party and bag lists) rise in when opened and the row icon hops when selected; reward items pop out of their cards with a wobble; every screen except Battle settles in from a 3.5% zoom. New setting Animations > Menu animations (settings v11, default on); Disable all animations or Menu animations off = no menu motion, Battle motion Reduced = short fades with no bounce, Animation speed scales the timings. Registry ids `ui.cursor/press/popup/page/reward`. Tests `tests/unit/uiMotion.test.ts`, `tests/e2e/wiiMotion.spec.ts`. No art imported (all drawn). Slice 2: popups stop taking input the moment they close, then sink and fade (160 ms); the Hub tiles and the Trainer Select grid use the same gliding cursor (the grid's gold frames are gone); the map's node ring glides from the node it left; a screen that redraws itself (shop after a buy, map after a change) skips the zoom, popup rise and menu slide-in so repeated actions stay snappy (`noteSceneEnter`, `justRedrawn`). Battle menus use `Menu`, so they have the cursor too. Slice 3: a `Menu` that closes stops taking input at once, then fades and drifts 10 px (160 ms) before it is removed.
