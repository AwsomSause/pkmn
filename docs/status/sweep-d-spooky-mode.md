# Sweep D: Spooky Mode content (5.12)

Built: five Spooky Mode-only map events (three clue stops, the Hexed Keeper boss, the Hollow Mirror finale; `mode: "spooky"` on an event, `modeStop` makes the boss and finale always get a stop once their clue flags are met); mode shop stock (`balance.modeShops.spooky`: Reaper Cloth, Scroll of Darkness, Soothe Bell); battle opening lines (ordinary and boss); four objectives shown on the map (4 badges, 3 clues, keeper, finale) counted from run counters (`core/modeObjectives.ts`).
Not built: mode-specific NPCs, a curated boss roster beyond the Keeper and Mirror Witch (both use the Hex Maniac class sprite), an Event Archive return window.
