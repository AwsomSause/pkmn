- Trainer tiers (M10 §2; `core/trainerTiers.ts`, data `src/data/trainerTiers.json`, no save version change): ordinary trainers climb Early → Developing → Experienced → Advanced → Elite (the Champion tier is reserved for bosses, which keep their authored teams) by a score of stage number + party-strength levels + earlier wins over the class + rematch/importance (`score` weights). Each tier sets, per class: the chance a member comes from the class's species rung (Bug Catcher: larvae → cocoons → Butterfree/Heracross → Scizor/Volcarona), a stronger same-type attack, held items from the class list, training stacks in the class's stat (ace most) and the trainer AI. Advanced and Elite add class strategy moves (lead: hazards, weather, status, e.g. Sticky Web and Toxic Spikes; ace: setup and signature attacks). Memory (`tm:*` story flags, written after a won ordinary-trainer fight): a class that remembers brings back the Pokémon you beat one stage evolved (+2 levels) and a move for the type that beat it (60% chance; Youngster is a static class). Early trainers are untouched. Every roll uses its own seed from the run seed and node, never the gameplay streams. Tests `tests/unit/trainerTiers.test.ts`. Limited: no intro line says a trainer remembers you; no "beat you earlier so it is confident" (a loss ends the run); bosses, rivals and post-100 teams not tiered here (importance weight is ready for them).
