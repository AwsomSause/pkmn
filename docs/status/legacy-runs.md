The Hub stage shows the rotation instead of a random Pokémon: the saved run first, then up to five past Trainers picked by weight (score + recent bonus, last visit's picks cool down), fading between them, with a gold ★ for memorable runs and a rare line (§1.3). Hall of Fame lists ranked rivals, rivals that finished regions off-screen and deep rivalries, with fame, badges and story wins (§8.1). The run briefing sometimes remembers how the last run ended (§8.2), and tells a story loss to a rival (M12) apart from a failed run.
