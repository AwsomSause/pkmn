# Sweep C: Starter Lab extras (5.18)

Built: categories Challenge Sets and Special Specimens; two challenge pools (Underdogs, One of a Kind: no-evolution Pokémon); a Special Specimen pool of legendary/mythical first stages (`specimens: true`) that start `balance.specialSpecimen.levelPenalty` (3) levels lower and only use the Standard draft rule; per-species mastery frames and badge glyphs (Bronze to Master) in the Species Mastery list (`RANK_BADGES`).
