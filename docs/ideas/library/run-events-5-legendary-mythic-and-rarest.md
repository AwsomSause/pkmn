# Run Events 5: Legendary, Mythic and Once-in-a-Hundred-Hours Events (RE-E01 to RE-E66)

Design only, nothing built. Part of the run-event library. Rarity C/U/R/VR/M, Size S/M/L/XL.
Most are **VR or M**: a roll per run of roughly 1 in 50 to 1 in 2000, never guaranteed. A pity counter (kept in the profile, never in run RNG) slowly raises the odds so a long-time player eventually sees them. Each is skippable, never blocks progress, and never uses preview or animation RNG.

**RE-E01 The Weather Dragon's Passing** · VR · L
Trigger: storm node, region with sky legends. Scene: the clouds part around a long shape. Outcomes: bow (party gains a one-stage weather immunity), chase (a minimal catch chance fight, high risk), sing (it drops a Rain/Sun-dance trinket). Reward/Cost: immunity. Variations: three sky-dragon variants.

**RE-E02 Beasts of the Burning Tower** · VR · L
Trigger: ruin node + fire team. Scene: three beasts run past. Outcomes: follow one (it leads to a hidden shrine), try to catch (hard chase minigame), step aside (blessing, small). Reward/Cost: path. Variations: which beast follows depends on your party's type.

**RE-E03 The Time Walker's Gift** · M · XL
Trigger: very rare, a mossy forest shrine. Scene: green light, a tiny rewind. Outcomes: ask for a second chance (undo the last battle's result once this run), ask for knowledge (see the next 3 map nodes), ask for nothing (a permanent Legacy "Friend of Time" mark). Reward/Cost: undo once. Variations: Legacy mark changes later forests.

**RE-E04 Lakeside Pixies of Will** · VR · L
