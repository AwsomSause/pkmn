# Run Events 7: People, Rivals, Trainers and Social Moments (RE-G01 to RE-G62)

Design only, nothing built. Part of the run-event library. Rarity C/U/R/VR/M, Size S/M/L/XL.
Characters are drawn from the existing trainer classes, rival catalog (personalities, styles, offscreen events), gym leaders, Elite Four and villain teams. None repeats a "Meet <class> <name>" event already built.

**RE-G01 The Rival Brings Soup** · C · S
Trigger: rival bond medium+, party hurt. Scene: they leave a thermos on your bench. Outcomes: eat (heal 20%), thank them (relationship +1), pour it out (relationship -1). Reward/Cost: heal. Variations: stoic rivals pretend it was "extra".
