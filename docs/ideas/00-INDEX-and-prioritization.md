## Implementation notes for a future build thread
- Every random pick uses a named seeded stream; a new stream must never change existing rolls.
- New persistent state needs a versioned save migration (profile, run) and a Zod schema.
- Presentation-only ideas (VA, many BT) must never alter battle outcomes and must honor motion, intensity, skip and audio settings.
- Backend ideas (SC marked XL) have offline fallbacks: share codes, files, QR.
- Next step suggested: Kice reviews by ID; a consolidation thread merges overlaps and produces an approved shortlist before anything is built.
