# Whole-Game Events F: Secrets, Extremely Rare Events, Meta Moments (GWE-F01 to F36)

Field key and shared rules as in file A (*Desc, How, Trigger, Feel, Deps, Rar, Pay, Cx, Bal*). Mostly XR (once in hundreds of hours). Real-world clock facts are read once into the seed so tests stay deterministic. Any fourth-wall moment is skippable and can be turned off in settings.

---
