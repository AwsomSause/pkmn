# Master Idea Library 09: Long-Term Progression & Replayability (LP-001 to LP-080)

Legend and fields as in file 01. Design only. Complements Legacy, Mastery, Hall of Fame, Nemesis and the profile/run save split.

## A. Meta-progression structures

**LP-001 Hub Expansion Tree** — The Hub grows through branches (Lab, Gym, Market, Garden); each unlocks run options. *Trigger:* currency. *Feel:* base-building. *Rarity:* Always. *Cx:* L. *Deps:* Hub. *Balance:* avoid mandatory branches.

**LP-002 Generational Ascent** — Each completed run counts as a generation; generations unlock heritage perks. *Trigger:* run end. *Feel:* saga. *Rarity:* Always. *Cx:* L. *Deps:* Legacy. *Balance:* capped.

**LP-003 Wishes Instead Of Stats** — Meta currency buys wishes that alter run rules not power (more events, more rivals). *Trigger:* Hub. *Feel:* variety not power. *Rarity:* Always. *Cx:* M. *Deps:* mutators. *Balance:* none.

**LP-004 Season Pass Of Challenges** — Each season has a list of challenges unlocking cosmetics. *Trigger:* season. *Feel:* goals. *Rarity:* Seasonal. *Cx:* M. *Deps:* weekly events. *Balance:* free.

**LP-005 Skill Mastery Not Stats** — Meta unlocks are knowledge (identifications) not stats. *Trigger:* play. *Feel:* learn. *Rarity:* Always. *Cx:* M. *Deps:* codex. *Balance:* none.

**LP-006 Unlock By Discovery** — Items unlock when discovered, not bought. *Trigger:* play. *Feel:* exploring. *Rarity:* Always. *Cx:* M. *Deps:* unlocks. *Balance:* none.

**LP-007 Prestige Worlds** — Beating the game opens harder worlds with new rules each. *Trigger:* clear. *Feel:* endgame. *Rarity:* Long-term. *Cx:* L. *Deps:* difficulty. *Balance:* tuned.

**LP-008 Daily Quest Chain** — Daily quests chaining into weekly goals. *Trigger:* date. *Feel:* habit. *Rarity:* Daily. *Cx:* M. *Deps:* quests. *Balance:* opt.

**LP-009 Species Roadmaps** — Each species has a personal progression with unlockable forms and moves via mastery. *Trigger:* mastery. *Feel:* attachments. *Rarity:* Long-term. *Cx:* L. *Deps:* Species Mastery. *Balance:* tuned.

**LP-010 Run Modifiers Shop** — Spend meta to buy modifiers that increase difficulty for better rewards. *Trigger:* Hub. *Feel:* self-set challenge. *Rarity:* Always. *Cx:* M. *Deps:* mutators. *Balance:* tuned.
