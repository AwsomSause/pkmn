# Master Idea Library 13: Narrative Depth & Player-Driven Storytelling (NR-001 to NR-080)

Legend and fields as in file 01. Design only. Aims to turn run state into story without hand-authoring every branch.

## A. Story frameworks

**NR-001 Three-Act Run Spine** — Each run follows a flexible spine (Setup, Complication, Reckoning) with the director steering events toward act beats. *Trigger:* run. *Feel:* every run reads as a story. *Rarity:* Always. *Cx:* L. *Deps:* encounter director. *Balance:* tuned.

**NR-002 Theme Of The Run** — A run is assigned a theme (Redemption, Rivalry, Found Family) that tilts event picks and the ending. *Trigger:* run start. *Feel:* coherence. *Rarity:* Always. *Cx:* M. *Deps:* director. *Balance:* tuned.

**NR-003 Character Arcs For Party Members** — Each party member can have an arc (overcome fear, prove themselves) with beats across the run. *Trigger:* mood. *Feel:* investment. *Rarity:* Always. *Cx:* L. *Deps:* mood, events. *Balance:* tuned.

**NR-004 Chekhov's Items** — Items obtained early are paid off later (the strange key opens a door in act 3). *Trigger:* loot. *Feel:* clever. *Rarity:* Common. *Cx:* M. *Deps:* event chains. *Balance:* tuned.

**NR-005 Foreshadow Tracker** — Director tracks setups and ensures payoff before the end. *Trigger:* run. *Feel:* satisfying. *Rarity:* Always. *Cx:* L. *Deps:* director. *Balance:* none.

**NR-006 Recurring Motif Engine** — Motifs (a red scarf, a lullaby) recur across scenes. *Trigger:* run. *Feel:* literary. *Rarity:* Always. *Cx:* M. *Deps:* text. *Balance:* none.

**NR-007 Narrator Voice Options** — Choose narrator style (documentary, bard, sportscaster, gentle storyteller). *Trigger:* setting. *Feel:* tone. *Rarity:* Setting. *Cx:* M. *Deps:* dialogue. *Balance:* none.

**NR-008 Chapter Cards** — Each act opens with a summary card of choices so far. *Trigger:* act. *Feel:* recap. *Rarity:* Always. *Cx:* S. *Deps:* run history. *Balance:* none.

**NR-009 Story Seeds From Past Runs** — Unresolved threads from earlier runs resume. *Trigger:* Legacy. *Feel:* continuity. *Rarity:* Common. *Cx:* L. *Deps:* Legacy. *Balance:* none.

**NR-010 Unreliable Narrator Event** — A rare run where the narrator lies; truth emerges later. *Trigger:* roll. *Feel:* twisty. *Rarity:* Extremely rare. *Cx:* M. *Deps:* dialogue. *Balance:* none.
