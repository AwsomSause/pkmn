# Run Events 6: Spectacles and Run-Defining Moments (RE-F01 to RE-F60)

Design only, nothing built. Part of the run-event library. Rarity C/U/R/VR/M, Size S/M/L/XL.
These are the **big swings**: a choice that reshapes the rest of a run (a new rule, a rival turned ally, a second route, a doomed countdown). Each states a **Run Mutation**: the lasting change recorded in the run so saves and replays stay deterministic. Most appear once per run at most.

**RE-F01 The Fork in the World** · R · XL
Trigger: end of region 2. Scene: the map splits into two full routes. Outcomes: Sunlit Road (easier fights, fewer rewards), Moonlit Road (harder, richer, rarer events). Run Mutation: route tag shapes event pools for 2 regions. Variations: a third secret road if you hold the right key.

**RE-F02 A Rival's Coup** · R · XL
Trigger: rival bond high, region 3+. Scene: the rival announces they will take the next gym first. Outcomes: race them (a timed route; win = their badge goes to you), join forces (shared team of 6), sabotage. Run Mutation: rival status changes (ally or hostile). Variations: personality.
